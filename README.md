# كلام يفتح كلام — إصدار المشاركة والمزامنة

يحتوي التطبيق على 135 سؤالًا عربيًا، مفضلة، مكتمل، ملاحظات لكل سؤال، ومتتبع توافق 15 محورًا. يحتفظ بنسخة محلية ويزامن بيانات الغرفة المشتركة عبر Supabase عند إعداده.

## مهم قبل النشر
GitHub Pages يستضيف ملفات ثابتة فقط؛ لذلك نستخدم Supabase كقاعدة بيانات خارجية. لن تعمل المزامنة بين شخصين قبل إعداد Supabase وملف `config.js`.

## الإعداد مرة واحدة
1. أنشئ مشروعًا في https://supabase.com/ وسجّل الدخول إلى لوحة التحكم.
2. افتح SQL Editor، ثم الصق محتوى `supabase-setup.sql` وشغّله.
3. من إعدادات المشروع انسخ **Project URL** و**publishable/anon key**.
4. افتح `config.js` واستبدل القيمتين `PASTE_SUPABASE_PROJECT_URL_HERE` و`PASTE_SUPABASE_PUBLISHABLE_OR_ANON_KEY_HERE` بالقيم الفعلية. لا تستخدم `service_role` أو أي secret key في المتصفح.
5. ارفع كل الملفات الموجودة في المجلد إلى جذر مستودع GitHub Pages، بما فيها `config.js` و`supabase-setup.sql`.
6. افتح موقع GitHub Pages. سيُنشأ معرّف غرفة عشوائي تلقائيًا في الرابط. اضغط «نسخ رابط المشاركة» وأرسل الرابط للطرف الآخر؛ يجب أن يفتح نفس الرابط بالضبط.

## نشر GitHub Pages
في المستودع: Settings → Pages → Build and deployment → Deploy from a branch → اختر `main` و`/(root)` ثم Save. انتظر اكتمال النشر ثم افتح الرابط الظاهر في صفحة Pages.

## فحص سريع
- تأكد أن `index.html`, `app.js`, `config.js`, `manifest.json`, `sw.js`, `icon.svg` كلها في جذر المستودع، لا داخل مجلد إضافي.
- افتح DevTools → Console/Network إن لم تظهر الأسئلة. يجب أن يحمّل `app.js` بحالة 200.
- إذا ظهر إصدار قديم، اعمل hard refresh (Ctrl+F5) أو احذف بيانات الموقع/Service Worker ثم افتحه من جديد.
- تأكد أن SQL اشتغل وأن عنوان Supabase والمفتاح صحيحان.

## الخصوصية
رابط الغرفة يعمل كرمز وصول: أي شخص يمتلك الرابط يستطيع مشاهدة بيانات الغرفة وتعديلها. لا تشارك الرابط علنًا ولا تكتبوا كلمات مرور أو معلومات شديدة الحساسية. استخدم فقط المفتاح العام publishable/anon؛ أبدًا لا تضع service_role/secret key في ملفات الواجهة.

## تخزين محلي
في حال لم يتم ضبط Supabase، يظل التطبيق قادرًا على حفظ البيانات على الجهاز نفسه، لكن لن تتم المشاركة أو المزامنة عبر الأجهزة.
