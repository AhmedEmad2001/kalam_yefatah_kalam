# كلام يفتح كلام

تطبيق ويب عربي RTL يضم 135 سؤالًا: 45 سؤالًا أساسيًا و90 سؤال توافق عميق في 15 محورًا.

## التشغيل
- افتح `index.html` للتجربة الأساسية.
- لتفعيل العمل دون إنترنت: شغّل `python -m http.server 8000` داخل المجلد ثم افتح `http://localhost:8000`. يمكن أيضًا نشره على HTTPS.
- Service Worker لا يعمل عادةً عبر `file://`؛ يجب فتح التطبيق من localhost أو HTTPS وتحمليه مرة أولى قبل الاستخدام دون اتصال.

## المزايا
RTL متجاوب، بحث وتصفية، سؤال عشوائي، السابق/التالي، مفضلة، إكمال الأسئلة، ملاحظات لكل سؤال، متتبع توافق 15 محورًا، حفظ تلقائي في localStorage، استيراد/تصدير JSON، PWA وتخزين مؤقت دون إنترنت.

## الخصوصية
لا يوجد backend ولا تُرسل البيانات لخادم؛ التخزين محلي في المتصفح الحالي. احتفظ بنسخة عبر التصدير عند الحاجة.

## الملفات
`index.html` الواجهة، `app.js` الأسئلة والمنطق، `manifest.json` إعدادات PWA، `sw.js` التخزين المؤقت، `icon.svg` الأيقونة.
